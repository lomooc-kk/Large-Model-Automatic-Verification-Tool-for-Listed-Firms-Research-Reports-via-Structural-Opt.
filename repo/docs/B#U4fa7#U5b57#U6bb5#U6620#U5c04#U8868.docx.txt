B 侧字段映射表
研报纠错助手 · PDF 解析模块（成员 B）· 与 A 冻结的统一字段对齐
A 于 9 月 23 日冻结的统一字段为：公司、指标、数值、单位、期间、口径、文件及页码。本表说明每个字段由解析结果的哪一层提供、取值方式与边界，供 C（核查逻辑）与 D（前端导出）直接对接。解析模块只提供事实层数据与位置，口径判定属于核查模块的职责，本模块保留原文以供判定。
一、字段映射
统一字段
取自解析结果的哪一层
字段路径
取值方式与边界
公司
文档元信息 + 首页标题块
doc.doc_id、blocks[type=heading]（第 1 页）
文件名与首页标题二选一；解析不臆造公司名，取不到就留空由上游补
指标
表格单元格首列；正文句子
cells[col=0].text、sentences[].text
表格取行标签；正文由 C 侧按指标词表匹配，本模块提供句级文本与坐标
数值
表格单元格；正文句子
cells[].text、sentences[].text
原样保留千分位、百分号、括号负数与单位后缀，不做数值规整，避免改写失真
单位
表头行与单元格文本；图表来源行
cells[row=0].text、caption、source_note
单位可能出现在表头（如“单位：百万元”）或单元格内（如“8,420 万元”），两种都要查
期间
表头行；正文句子中的时间词
cells[row=0].text、sentences[].text
年份与标记（2024A/2025E）原样保留；报告期由 C 侧按需归一
口径
不由本模块判定
—（提供 sentences[].text 与 bbox）
归母／扣非、单季／累计等口径判定属 C 的职责；本模块保证原文与位置可回溯
文件
文档元信息
doc.source_path、doc.sha256
路径为本地相对路径，sha256 用于确认引用的是同一份文件
页码
页级与块级
pages[].page、blocks[].block_id
页码从 1 开始；block_id 形如 p117_t13，可直接用于定位
二、用于证据展示的附加字段
字段
含义
使用方式
bbox
区块在页面上的矩形坐标（左上原点，单位为点）
前端按渲染缩放换算后画高亮框；高亮不稳定时退化为页码加原文摘录
sentences[].bbox
句子的近似坐标（按行内字符占比切分）
用于把结论引用到某一句话
cells[].bbox
表格单元格坐标
用于把结论定位到表内具体格子
caption / source_note
图表标题与资料来源
作为证据链的一部分展示来源
confidence
OCR 文本的平均置信度（仅 OCR 块有）
低于阈值时提示人工核对

四、约定
• 本模块只做事实层：不做单位换算、不做口径判定、不改写数值文本，避免在解析阶段引入不可追溯的加工。
• 表格引用到单元格（block_id + row + col），正文引用到句子（block_id + sentences 索引），两者都能回链到页面坐标。
• 字段缺失时的行为：取不到就留空，不猜；页面状态为 fail 的页不参与自动结论。
• 字段变更由 A 统一通知，本模块按新字段同步更新本表与数据契约（schemas/parse_result.schema.json）。
