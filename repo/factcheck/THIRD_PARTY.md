# C 第三方依赖与实现边界

本模块复用 B 的 `yjparse` 解析、质量状态、页码和坐标，没有把第三方 PDF 引擎或模型识字能力当作 C 自研能力。B 的依赖与许可说明见 `../pdfparse/THIRD_PARTY.md`。

| 组件 | 本次版本 | 使用范围 |
| --- | --- | --- |
| Python | 3.12.14 | 标准库：Decimal、JSON/CSV、ZIP/XML、HTTP、unittest |
| pdfplumber | 0.11.9 | B 默认解析引擎，保留文本行和表格位置 |
| PyMuPDF | 1.27.2.3 | B 可选引擎、测试和页面验证；其许可说明沿用 B 登记 |
| pypdf | 6.10.0 | 独立核对原 PDF 页数、页尺寸 |
| Pillow | 12.3.0 | B 预览及相关测试 |
| reportlab | 4.4.9 | 测试中生成可复现中文 PDF，不用于生成财务答案 |
| jsonschema | 4.26.0 | 测试结果契约 |
| Streamlit / RapidOCR / ONNX Runtime | 1.64.0 / 3.9.2 / 1.30.0 | B 完整回归测试，包括实际页面和 OCR |

大模型客户端由标准库 HTTP 实现，不内置权重或指定商业模型。实际部署者配置模型名、版本和端点；本轮仅验证接口与错误处理，未使用付费外部模型。

核心代码不包含公司专属财务答案。E 原始材料仍在工作区样本目录，未加入仓库；只读评测工具中的标注对照与算法运行分离。
