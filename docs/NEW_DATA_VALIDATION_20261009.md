# 新数据节点迭代结果 · 2026-10-09

旧数据只用于发现典型问题，新开发集用于调整，新验证集用于检验改动。旧 FinED、442 篇和历史配对样本没有进入本轮模型输入、监督示例或效果分母；前端自动加载旧 examples.dev.json 的路径也已移除，direct/Pi 两个入口有回归测试。

本轮结论：中文段落纠错候选在这批新验证数据上改善；复杂声明判读链暂不替换基础节点。Pi 和真实 OpenViking 已可运行，检索链路成功不等于业务判断通过验收。所有候选判断保留待复核状态。

“结构化＋示例”相对“仅结构化”的增量仅1.37个百分点，配对区间为−4.11至+6.59，尚不能单独确认示例带来稳定增益。10条正常文本的4→3→2只是本批计数。全部246次预测均完成，失败项没有被删除；规范化编辑定义为两边使用同一diff分段，本批187个规范化金标编辑与170个上游标注条目不是同一分母。

采用范围：后续中文段落纠错优先沿用结构化候选及开发示例进行复验。尚未将它强行映射为十五类检测器或替换GUI默认业务链。

## 已做的节点和流程修改

- 输出上限从4096调整到16384，解决开发试跑中观察到的截断；预算与原账本保留，无自动重试。
- 中文节点分项检查事实、词语、语法、标点，约束必要局部修改；加入4条经过来源核验的开发示例。
- 声明节点对齐主体、期间、指标、数值、单位和口径；仅对唯一空白差异映射回原文，引用不改数字或标点。
- 可选固定算术使用原文取数与Decimal复算；求和/求差不豁免单位未知，比率需要明确的比率/百分比语境。运算正确不代表模型选择的指标和期间必然正确。
- Pi最多搜索两次，同一来源片段合并展示，相同证据组合不重复付费重核；必须先检索、读取才能重核。
- 输入与答案分离，开发示例在独立进程核验后按字节哈希绑定；冻结运行计划、源码、评分器及输入，推理完成后再评分。

本轮使用了上下文示例，**没有更新模型权重**。186条开发SFT材料已准备；涉及外部事实但没有证据的条目不因此获准作为有证据事实核验训练材料。
