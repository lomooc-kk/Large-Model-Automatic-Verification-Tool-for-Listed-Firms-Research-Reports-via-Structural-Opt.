# 编号重复与段落角色辅助实验

2026-10-10 的固定五篇对照显示，改动后的严格 F1 从 68.18% 升至 71.43%，但少报的两条中，有一条是原文支持、金标未收录的术语疑点。该实验不能据此认定净改善，默认保持关闭。

## 实现与边界

`yjcheck.numbered_repetition_context.source_numbered_repeat_checks` 只从当前可见原文提取相邻编号条目的字面共同部分，保留编号、两个成员的位置、列表导语、必要上文及右侧新增内容。它不生成错误、不决定业务真伪，也不读取金标。

识别范围限于括号编号、同一段落、连续同级编号和完整前缀复写。裸数字、嵌套或重置编号、混合样式、三个相同成员及示例语境弃权。裸数字可能是数量、期限或资本层级，不能一律剥离为序号。

模型消息只带必要的两个原文成员和语境，不携带多份相同正文。辅助超出当前输入预算时逐项省略，原始 `contexts` 保留；不能为了提供辅助而跳过本来可读的原文。导语句号与中文引号保持原位，所有位置为原文 Unicode 字符偏移。

## 显式实验接口

```python
from yjcheck.text_review import detect_text

report = detect_text(
    source_text,
    document_id=source_id,
    chat=budgeted_chat,
    redundancy_context_experiment=True,
)
```

该参数同时打开编号辅助和段落角色提示。默认值为 `False`；现有 CLI、PI 路径及回归 runner 沿用默认行为。只有显式布尔值有效。实验提示强调主题与展开、摘要与正文、不同消息来源以及新增条件的区分，且不把同级标题复制一概豁免。

## 已验证与未验证

五篇为旧错误开发样本，单次模型响应，使用相同文本、金标、评分器和运行配置。两项改动同时启用，不能分离各自贡献，也不能排除响应波动。没有新样本泛化成绩，没有权重训练，未达到 95% 目标。

现有证据支持：000364 的主题后原因展开不应整句报冗余；000609 的局部重复可以更准确地引用，同时明确保留后续新增内容。反面证据是 000506 的“变成坏账准备”提示消失，000646 的日期类别和双成员定位仍不稳定。

恢复默认后，五篇的请求与冻结基线逐字相同；显式开启实验时与冻结候选请求逐字相同。默认又经过仅使用已有响应、禁止缺失时联网的完整重放，原始候选和全部审核提示与基线一致，新增调用和费用均为零。

后续应优先尝试有独立输入输出边界的冗余复核节点，验证它是否保留其他类别和新增信息。不能按文档挑选最优版本，也不能为了消除机械 FP 删掉有原文依据的提示。

证据：`output/known-error-repair-20261009/r10-list5-comparison.json`、`r10-experiment-switch-validation.json`、`r10-default-replay-validation.json`，以及同目录的两个冻结模型运行与分析文件夹。
