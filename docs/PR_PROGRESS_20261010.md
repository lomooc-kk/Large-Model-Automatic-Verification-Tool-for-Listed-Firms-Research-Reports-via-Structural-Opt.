本版交付可运行的可选 Pi 调度、OpenViking 适配器、节点修复及数据准入/评测工具。代码已做工程验证，也已开始新的中文研报诊断；**95% 旧错例目标尚未达到，新研报尚没有完整业务金标，因此没有完整十五类准确率或 F1 验收结论。**

## 交付内容

- `agent_runtime/` 使用实际 Pi Agent SDK；Python 工作流提供检测、检索、读取与再次核查工具。CLI 和前端有显式启用入口。模型调度有轮次、时限、token 与共享费用约束。
- `pdfparse/src/yjparse/openviking.py` 连接真实 OpenViking HTTP 服务，提供上传、入库、检索和回读；来源和文件哈希验证通过后才进入核查。本地 embedding 与服务启停脚本随代码提供，密钥、模型权重及数据库不入库。
- 文本节点补充来源结构、时间/日期、算术、数列、占比及冗余上下文，保留候选、引用、拒绝原因与执行失败；显式判定合同和来源质量提示仍是可选实验接口。
- 数据工具区分开发、迭代验证与封存候选。旧数据用于诊断与另行授权的旧错例回归，不进入新集效果分母；中文编辑任务和英文证据声明任务分开评分。前端已移除旧开发示例自动加载。
- 前端展示 Pi 未完成状态和补证过程，保留人工复核入口；PDF 导出行高修复有回归覆盖。

## 插件的验证边界

Pi/OpenViking 已有本地真实服务与合成集成验证。此前 FinanceBench 的 14 条迭代验证中，OpenViking 14/14 检索并回读预期节选，但标签一致只有 7/14，基础节点为 12/14；检索库是 7 份节选/9 个块，信息条件不完全相同，标签仍有精度争议。不能由此证明插件提升业务正确率。

工程测试使用合成样例、临时目录和本地 HTTP fixture；无需旧金标、外部测试集或真实模型密钥。按 [构建与测试说明](PI_OPENVIKING_IMPLEMENTATION.md) 安装依赖、构建 Node 运行时再执行。
